# Root Cause

Wins Above Replacement for Test cricket, built from Cricsheet's ball-by-ball archive (2001–2026, 914 matches, 1.76 million deliveries). Adjusted for opposition quality, pitch conditions, country-specific factors, and leverage.

**Live:** https://sid36252.github.io/root-cause/

Companion piece on how the model was actually built and tested: [Measure Twice](https://sid36252.github.io/measure-twice/)
